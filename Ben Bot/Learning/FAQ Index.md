## How a new FAQ is added
1. Ben sees the same question several times, or an admin answers an escalation with "add to FAQ".
2. Ben creates a note in `FAQ/` from `Templates/FAQ Entry`, with `status: draft`.
3. An admin approves it in the admin portal. Ben sets `status: approved`, adds the line to this index, and writes to [[Knowledge Changelog]].
