# Admin inbox

This is the record of what the admin portal shows. Ben adds an item for every escalation. An admin replies in the admin portal, and the reply is then recorded here and in [[Unsure Questions Index]].

## How an admin replies
Choose one for each item in the admin portal:
1. **This user only.** Ben answers this person and nothing else changes.
2. **Add to FAQ.** Ben creates a draft FAQ note for approval (see [[FAQ Index]]).
3. **Update a knowledge note.** Name the note and paste the new line. The change is recorded in [[Knowledge Changelog]].
4. **Not for Ben.** Ben tells users to contact HQ directly for this one.
